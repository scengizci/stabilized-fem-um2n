# Benchmark problems

This directory contains the mathematical definitions and baseline numerical configurations of the four two-dimensional benchmarks considered in the associated manuscript, *Curvature- and stabilization-informed neural mesh adaptation for stabilized finite element computations of convection-dominated transport*.

| Test | Problem | Description |
| --- | --- | --- |
| [Test 1](test01_convection_diffusion/README.md) | Stationary convection–diffusion | Scalar transport with a sharp interior layer and outflow boundary layers |
| [Test 2](test02_burgers/README.md) | Transient viscous Burgers | Coupled nonlinear transport with a moving sharp transition |
| [Test 3](test03_kovasznay/README.md) | Steady Kovasznay flow | Incompressible Navier–Stokes flow with an analytical solution |
| [Test 4](test04_cylinder/README.md) | Unsteady cylinder flow | Time-dependent incompressible flow past a circular cylinder |

**Repository status:** The benchmark definitions are available. Solver implementations, figures, numerical output, and step-by-step reproduction instructions are **work in progress** and are not yet included.
